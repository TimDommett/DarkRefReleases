# CLAUDE.md - DarkRef Releases

This repo is the public download page for DarkRef: the README and the GitHub
releases that carry the Windows builds. The app's source lives in
`TimDommett/DarkRefElectron`, and its CLAUDE.md is the main guide.

## Tasks live in Tickets (project DR)

Every DarkRef task, including work on this repo, lives in the private
**Tickets** tracker: org `keystone-studios`, project **DR** (DarkRef),
https://tickets-tangent.netlify.app/keystone-studios/project/DR. Use the
`mcp__Tickets__*` tools (load them with ToolSearch). Linear is no longer used.

- **Requests become tickets.** When Tim asks for a change, create its DR ticket
  first, assigned to `claude`, quoting his words. A question doesn't need a
  ticket: just answer it.
- **Working a ticket.** Move it to In Progress, link the session and the PR with
  `add_link`, put the ticket ID (`DR-NN`) in the PR, do the work, add a short
  comment with evidence, and move it to **In Review**. Tim moves it to Done.
  Never mark Done yourself.
- **Handing work back.** Anything only Tim can do becomes a DR ticket assigned
  to him (`timdom11`), with numbered steps.
